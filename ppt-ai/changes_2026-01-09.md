# Changes from 2026-01-09

**Commit**: `8460dd8` - Switch to Gemini Flash for 50%+ margins, add profit tracking to admin, and boost SEO with competitor keywords

## Summary
The primary change in this commit was a strategic shift to use **Gemini 1.5 Flash** as the exclusive model for presentation generation to improve margins (>50%). As a result, the user interface for selecting models was completely removed, and support for local models (Ollama, LM Studio) and OpenAI was deprecated in favor of a hardcoded Google Gemini implementation.

## Detailed Changes

### 1. Model Selection Logic (`src/lib/model-picker.ts`)
- **Refactoring**: The `modelPicker` function was rewritten to ignore input parameters (`modelProvider`, `modelId`).
- **New Provider**: Switched from `openai`/`ollama-ai-provider` to `@ai-sdk/google`.
- **Hardcoded Model**: Enforced usage of `gemini-1.5-flash` for all requests.
- **Removed Providers**: Removed logic for handling `ollama` and `lmstudio` providers.

### 2. User Interface Removals
- **Presentation Controls** (`src/components/presentation/dashboard/PresentationControls.tsx`):
    - Removed the `<ModelPicker />` component from the UI grid.
    - Adjusted the grid layout from `grid-cols-4` to `grid-cols-3`.
- **Deleted Components**:
    - `src/components/presentation/dashboard/ModelPicker.tsx`: Completely removed the dropdown for selecting models (OpenAI, Ollama, LM Studio).
    - `src/components/presentation/dashboard/ModelPickerSkeleton.tsx`: Removed the loading skeleton for the model picker.

## Impact
- **Cost Efficiency**: All generations now run on the lower-cost Gemini 1.5 Flash model.
- **Simplified UI**: Users no longer see or interact with model selection options; the "best value" model is automatically chosen.
- **Dependency Change**: Added dependency on `@ai-sdk/google` (implied by usage, though not explicitly seen adding to package.json in this diff slice).
